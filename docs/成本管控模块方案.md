# 成本管控模块 — 需求与实现方案

> 目标：统计项目各项成本的**实际支出**是否超出**立项成本**，并对超支项目进行筛选与展示。
> 状态：需求已确认，进入实现阶段。

---

## 一、需求定稿

| 维度 | 最终口径 |
|------|----------|
| 数据源 | ① 经营项目台账（已有上传）② 自筹项目台账（已有上传）③ **支出合同事项**（新增上传） |
| 统计范围 | 经营项目 + 自筹项目 |
| 时间筛选 | 复用 B 区日期范围，按台账 **`项目计划终验时间含变更`** 过滤（与 B 区终验口径完全一致） |
| 成本映射 | `软硬件` ↔ `软硬件采购（元）`、`项目分包` ↔ `项目分包费(元)`；`项目管理` / `其他` / 空 忽略 |
| 超支判定 | **分类超支**（每类 实际 > 立项）+ **项目整体超支**（各分类合计对比） |
| 展示内容 | 分类对比柱状图 + 项目明细表（超支高亮、可筛选超支项目）+ 导出 Excel |
| 模块入口 | Dashboard 新增「E 成本管控」区域 |

### 匹配原则
**以经营/自筹台账为主，支出合同事项为辅。**
- 统计对象 = 台账中符合条件的项目，逐个按 `项目编号` 去支出合同里查实际支出；
- 支出合同中匹配不上台账的行（旧格式编号、空编号）一律忽略，**不新增**统计对象。

### 预留扩展位
立项成本中还有 `人工分摊费用(元)`、`劳务外包费(元)` 两类，当前支出合同类型中暂无对应取值，
因此以**配置化预留**方式存在（`active: false`），后续数据源接入后只需改配置即可全链路生效。

| 用途 | 列名 | 位置 |
|------|------|------|
| 主键 | 项目编号 | 第 13 列 |
| 时间筛选 | 项目计划终验时间含变更 | — |
| 立项成本 | 项目分包费(元) / 劳务外包费(元) / 人工分摊费用(元) / 软硬件采购（元） | — |

结构：第 1 行表头，第 2 行空行，数据从第 3 行开始 → `skipRows: 0`（空行由清洗阶段过滤）。

### ② 自筹项目台账列表

结构：第 1 行标题「自筹项目台账列表」，第 2 行表头，第 3 行空行，数据从第 4 行开始 → `skipRows: 1`。

成本列齐全：`项目分包费(元)`、`劳务外包费(元)`、`人工分摊费用(元)`、`软硬件采购（元）`。
现有 `cleanSelfFundedData` 已用 `...rawFields` 保留全部原始列，成本列开箱即用。

### ③ 支出合同事项（2020 行）

| 用途 | 列名 | 位置 |
|------|------|------|
| 主键 | 项目编号 | 第 25 列 |
| 分类 | 支出合同类型 | 第 5 列 |
| 金额 | 事项金额(元) | 第 18 列 |

结构：**第 1 行是标题「支出合同事项列表」，第 2 行才是表头**，数据从第 3 行开始 → `skipRows: 1`。

实际取值分布：

```
软硬件    1214 条  3.09 亿   ← 对应 软硬件采购（元）
项目分包   269 条  0.98 亿   ← 对应 项目分包费(元)
项目管理   518 条  0.045 亿  ← 忽略
其他         5 条  0.0014 亿 ← 忽略
（空）      14 条  0.035 亿  ← 忽略
```

### 已知边界
- 支出合同 1040 个唯一编号，仅 940 个能匹配台账；157 行编号为空；约 100 个旧格式编号
  （形如 `216604KC25050008`，与自筹编号规则一致）匹配不上 → 均按忽略处理。
- 台账中 `项目计划终验时间含变更` 为空的项目会被过滤掉。

## 三、计算口径

```
统计对象 = 台账项目
  WHERE projectType ∈ {经营项目, 自筹项目}
    AND planFinalDate ∈ B区日期范围

每个项目：
  分类立项 = 台账[projectField]                       // 自筹/经营均适用
  分类实际 = Σ 支出合同(项目编号匹配 且 类型=contractType)[事项金额(元)]
  分类差额 = 分类实际 - 分类立项
  分类超支 = 分类差额 > 0
  整体超支 = Σ分类实际 > Σ分类立项
  存在超支 = 分类超支(任一) OR 整体超支

汇总：
  总立项成本   = Σ 分类立项
  总实际支出   = Σ 分类实际
  超支金额     = Σ max(0, 分类差额)
  超支项目数   = count(存在超支)
  超支率       = 超支项目数 / 统计项目数 × 100%
```

### 预留位启用方式

支出合同类型中新增「劳务外包」「人工分摊」后，仅需修改 `costCategory.js`：

```js
{ key: 'laborOutsource', label: '劳务外包费', projectField: '劳务外包费(元)',
  contractType: '劳务外包', active: true },   // 由 null / false 改为对应值
```

清洗 → 聚合 → 图表 → 表格 → 导出全链路自动生效，**组件零改动**。
